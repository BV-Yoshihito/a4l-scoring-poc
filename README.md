# A4L ワンオペ入力PoC — 公開デモ

審判1名がスマホだけで試合を最後まで記録できる、野球スコアリングアプリの試作です。

**デモ**: https://bv-yoshihito.github.io/a4l-scoring-poc/

## このデモについて

- **単一HTMLファイルで動きます。** サーバもインストールも不要で、オフラインでも使えます
- **外部への通信はありません。** Webフォント・CDN・API呼び出しをひとつも使っていません
- **入力したデータは端末内（localStorage）にのみ保存されます。** どこにも送信されません
- **初期データは合成データです。** 実在の選手名・チーム名は含まれていません

このリポジトリは公開デモの配信専用です（`index.html` 1ファイルのみ）。開発用のソースは別リポジトリにあります。
